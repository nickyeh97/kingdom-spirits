# 經文池審稿單（G3，給組長／師母簽核）

> 準備日期：2026-10-30｜狀態：**待審**｜程式位置：`Assets/Core/Catalog.cs`
> 審稿標準：腓立比書 4:8（真實、可敬、公義、清潔、可愛、有美名）＋設計守則紅燈 #1（不比較）、#7（不羞辱、不罪惡感）。

遊戲的對話框每次只出現一句。**家長在平台寫了鼓勵的話時，一律優先顯示家長的話**；
家長沒寫時才用下面的經文。

## 怎麼審

1. 每一列看「目前文字」和「建議」，在最後一欄勾選：**✅ 用目前的**／**🔁 用建議的**／**✏️ 另外改**（寫在旁邊）。
2. 經文核對以**和合本**為準。下表的和合本原文是整理者依記憶列出，**簽核前請對照教會用的聖經**。
3. 審完把這份交回來（拍照或直接改這個檔都可以）。程式一次改好，不用逐句來回。

標記說明：
- **原文節錄**：跟和合本的字一樣，只截取一段。
- **意譯**：用自己的話講經文的意思，不是原文。**建議出處前面加「參」**（例：「（參 詩篇 139:14）」），孩子才不會以為聖經上就是這樣寫的。
- **待斟酌**：經文本身沒問題，但放在這個情境，孩子可能會誤會，所以附上替代經文。
